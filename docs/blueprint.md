# **App Name**: Oaktree Edge

## Core Features:

- Lead Capture and CRM Integration: Capture leads from the website and automatically push them into the Operations Portal CRM for tracking and management.
- Client Portfolio Management: Enable Oaktree staff to manage client portfolios, track service status, and add internal notes.
- Document Vault: Securely store and categorize internal and client-facing documents with upload, tagging, and search capabilities.
- Client Report Generation: Generate client portfolio reports using pre-designed templates with one-click PDF export.
- Client Portal Authentication: Secure client login with individual usernames/passwords and encrypted session management.
- Portfolio Overview Dashboard: Provide clients with a dashboard summarizing their active services and key health indicators.
- AI-Powered Content Tool for Report Generation: Integrate AI-driven summarization of historical documents to improve portfolio report descriptions. The AI tool will analyze uploaded documents and use relevant information to supplement report details.

## Style Guidelines:

- Primary color: Deep teal (#0F3133) to convey trust and stability, aligning with Oaktree’s brand.
- Background color: Light gray (#F0F0F0), a very desaturated tint of the primary color, provides a clean and professional backdrop to ensure readability and focus on content.
- Accent color: Gold (#D4AF37), an analogous color, used for call-to-action buttons and highlights, symbolizing quality and premium service.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will be used for a modern, machined and neutral look, making the application clean and user-friendly. This font works well for headlines and body text, maintaining readability and professionalism.
- Use clean and professional icons related to finance and portfolio management.
- Maintain a clean and organized layout across all portals with clear navigation.
- Incorporate subtle animations to enhance user experience and provide feedback.
