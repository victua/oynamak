# **App Name**: Oynamak Sports Group

Public website and internal operations portal for Oynamak Sports Group Ltd, a sports enterprise delivering sports products, strategic partnerships, international exchange, sports tourism and sports technology.

## Core Features

- Public website: Home, About, Solutions (5 objectives), Events, Contact, Get Started.
- Consultation popup and lead form feeding the Operations Portal.
- Operations Portal (`/ops`): leads, customers, events, marketing, finance, reports.
- Client Portal (`/portal`): authenticated dashboard for partners.

## Style Guidelines

- Primary: dark navy blue `#0B2A5B` (`--primary`).
- Secondary: white, with a pale blue tint `#EAF1FB` for cards (`--secondary`).
- Accent: red `#D62839`, used sparingly for CTAs and highlights (`--accent`).
- Font: Mont.
- Layout: top info bar, white nav with a single CTA, very large headings, pale-blue rounded cards, photos with one large rounded corner (`rounded-brand`).
- Images: set paths in `src/lib/site-images.ts`; branded artwork is shown until a photo is supplied.
